# 01 — Project Scaffold

> **Goal:** stand up an empty but runnable Python package with `uv`, `ruff`, `pytest`, and a single `medixio` entrypoint. No FastAPI, no DB, no WhatsApp yet — just *the skeleton you can `uv run` against*.

---

## Why this step exists

Every later step assumes a working Python package: dependencies pinned, tests runnable, lint configured, code importable as `medixio`. Doing this in isolation means later steps don't fight tooling at the same time as new features.

You'll learn:

- How `pyproject.toml` + `uv` replace `requirements.txt` + manual `venv`.
- The "src layout" and why it stops accidental `import .` mistakes.
- How `[project.scripts]` turns a Python function into a CLI command.
- Why `uv.lock` is committed but `.venv/` is ignored.

## Prerequisites

- Python 3.12 installed (or just `uv` — it can install Python for you).
- `uv` installed: <https://docs.astral.sh/uv/getting-started/installation/>.
- No `venv/` or `.venv/` in the repo yet. If you previously made one by hand, delete it.

## Concepts (one-paragraph each)

**`uv`.** Like `pip + venv + pip-tools` collapsed into one fast Rust binary. `uv sync` reads `pyproject.toml`, creates `.venv/`, resolves a lockfile (`uv.lock`), and installs everything. `uv run <cmd>` runs `<cmd>` inside that `.venv` without you having to activate it.

**`pyproject.toml`.** The single config file for Python projects (PEP 621). Holds metadata, dependencies, scripts, and tool configs (ruff, pytest…). Replaces `setup.py`, `setup.cfg`, `requirements.txt`, `tox.ini` for most projects.

**Src layout.** Putting code under `src/medixio/` instead of `medixio/` at the repo root. Forces you to install the package before importing it, which catches "works on my machine because of CWD" bugs. Industry standard for libraries.

**Console script.** A line like `medixio = "medixio.main:run"` in `[project.scripts]` makes uv generate a tiny wrapper at `.venv/bin/medixio` that calls `medixio.main.run()`. Running `uv run medixio` is then equivalent to running that wrapper.

## Steps

### 1. Create `pyproject.toml`

```toml
[project]
name = "medixio"
version = "0.1.0"
description = "WhatsApp chatbot for managing medical appointments"
readme = "README.md"
requires-python = ">=3.12"
dependencies = []

[project.scripts]
medixio = "medixio.main:run"

[dependency-groups]
dev = [
    "ruff>=0.7.0",
    "pytest>=8.3.0",
    "pytest-asyncio>=0.24.0",
]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[tool.hatch.build.targets.wheel]
packages = ["src/medixio"]

[tool.ruff]
line-length = 100
target-version = "py312"
src = ["src"]

[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP", "SIM", "RUF"]
ignore = ["E501"]

[tool.pytest.ini_options]
asyncio_mode = "auto"
testpaths = ["tests"]
```

### 2. Pin Python version

Create `.python-version`:

```
3.12
```

`uv` honours this when creating `.venv`.

### 3. Add Python `.gitignore` entries

Append (or replace the Node-flavoured `.gitignore` with):

```
__pycache__/
*.py[cod]
.venv/
.ruff_cache/
.pytest_cache/
.coverage
*.egg-info/
```

### 4. Create source layout

```
src/medixio/__init__.py        # __version__ = "0.1.0"
src/medixio/main.py            # def run(): print("medixio running")
tests/__init__.py              # empty
tests/test_smoke.py            # asserts medixio importable
```

Minimal `main.py`:

```python
def run() -> None:
    print("medixio scaffold OK")


if __name__ == "__main__":
    run()
```

Minimal `tests/test_smoke.py`:

```python
import medixio


def test_version():
    assert medixio.__version__ == "0.1.0"
```

### 5. Sync and run

```bash
uv sync                  # creates .venv, installs project + dev deps, writes uv.lock
uv run medixio           # prints "medixio scaffold OK"
uv run pytest -q         # 1 passing test
uv run ruff check .      # no errors
uv run ruff format .     # formats in place
```

### 6. Commit


```bash
git add pyproject.toml uv.lock .python-version .gitignore src tests
git commit -m "scaffold: uv-managed Python package with ruff and pytest"
```

## Common gotchas

- **`VIRTUAL_ENV=venv does not match …`** — you ran `python -m venv venv` by hand earlier. Delete the `venv/` directory and let `uv sync` create `.venv/`. Don't mix the two.
- **`ModuleNotFoundError: No module named 'medixio'`** — `[tool.hatch.build.targets.wheel] packages = ["src/medixio"]` is missing or the path is wrong.
- **uv lockfile changes on every run** — make sure you committed `uv.lock`. Sync uses it as source of truth.
